# 🎵 Music Player

A sleek and responsive music player built using **HTML, CSS, and JavaScript**. It features a clean UI with album art, playback controls, volume adjustment, and a dynamic playlist — all running smoothly in the browser without any external frameworks.

## ✨ Features

- ▶️ Play / Pause functionality
- ⏮️ ⏭️ Previous / Next track navigation
- 🔀 Shuffle mode
- 🔁 Repeat mode
- 🎚️ Seekable progress bar with live time updates
- 🔊 Volume control
- 📃 Interactive playlist with active track highlighting
- 📱 Fully responsive design (mobile-friendly)

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- Vanilla JavaScript (DOM manipulation, Audio API)
